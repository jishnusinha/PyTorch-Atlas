# BS09 · Energy forecasting with an LSTM

Run `python python_projects/bs09_energy_forecast/train.py` for seeded daily/weekly synthetic hourly data. It uses chronological partitions, a training-only scaler, 24-step windows, a one-hour target, LSTM regression, and a persistence baseline. Values and metrics are generated by that run and do not describe an actual utility.

Optional `--csv local.csv` expects `timestamp,power`, sorts timestamps, and checks finite values. The CLI documents data parsing while the executable smoke validates all model and leakage contracts. Confirm hourly cadence, duplicate timestamps, missing intervals, and domain shift before adapting it to real data. Dependencies: PyTorch only; no download. Test with `python -m pytest -q python_projects/bs09_energy_forecast/test_smoke.py`.
